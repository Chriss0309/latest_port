# Projects

## MentorTrader
**Technologies:** Next.js, PostgreSQL, Stripe, AWS, Sentry
**Type:** Full-Stack Marketplace Platform

### Description
A comprehensive marketplace platform focused on connecting **day traders** with **credible online trading mentors**. Built to solve the problem of finding trustworthy trading education and mentorship in the financial markets space.

### Key Features
- **Marketplace Platform:** Created a platform connecting traders with verified mentors
- **Student Management Dashboards:** Featuring comprehensive dashboards for tracking progress and interactions
- **Fintech Partnerships:** Established partnerships with companies like **Kinfo** and **Whop**
- **Payment Integration:** Secure payment processing through Stripe
- **Monitoring:** Real-time error tracking and performance monitoring with Sentry

### Technical Highlights
- Implemented using **Next.js** with **Supabase** backend
- **OAuth2.0 authentication** for secure user management
- **PostgreSQL database** for reliable data storage
- **AWS S3 storage** for media and document management
- **Redis caching** for improved performance
- **Sentry monitoring** for production reliability
- **Stripe payment integration** for secure transactions

### Impact
- Onboarded **120+ active mentors**
- Achieved **2,000+ monthly visitors**
- Created sustainable revenue model through platform fees
- Built strong fintech partnerships expanding platform reach

## Faves
**Technologies:** Express.js, Firebase, TailwindCSS, Google Cloud
**Type:** Recommendation Curation Platform

### Description
Working with an **Apple engineer** to build a platform that **curates recommendations from influential figures**. The platform enables users to discover trusted recommendations with detailed context and citations while allowing community contributions through a managed workflow.

### Key Features
- **Recommendation Browsing:** Browse **1,000+ recommendations** with detailed citations
- **Public Submissions:** Community can submit recommendations
- **Admin Approval Workflow:** Managed approval system for quality control
- **Rich Citations:** Detailed source information and context for each recommendation
- **Responsive Design:** Bootstrap/Tailwind CSS frontend for all devices

### Technical Highlights
- Built with **Node.js** and **Firebase**
- Implemented **authentication** and **rate-limiting**
- **Joi validation** for data integrity
- **reCAPTCHA security** to prevent spam and abuse
- Responsive **Bootstrap/Tailwind CSS** frontend
- Deployed on **Google Cloud Functions** for serverless scalability

### Impact
- Curated **1,000+ recommendations** from influential figures
- Enabled community-driven content with quality control
- Collaboration with Apple engineer on platform development

## URL Shortener Website
**Technologies:** Ruby, HTML/CSS, JavaScript, PostgreSQL
**Type:** Full-Stack URL Management System

### Description
A **full-stack URL shortener** that converts long URLs into **compact, trackable links** with advanced analytics. Built with a focus on security, performance, and comprehensive tracking capabilities.

### Key Features
- **URL Shortening:** Convert long URLs into compact, shareable links
- **Advanced Analytics:** Track comprehensive metrics for each shortened URL
- **Click Metrics:** Detailed tracking of user interactions
- **Visitor Geolocation:** Precise location data for link visitors
- **Referral Sources:** Track where traffic is coming from
- **Original Page Titles:** Capture and display source page information

### Technical Highlights
- Architected using **Rails 8** and **PostgreSQL**
- Styled with **Tailwind CSS** for modern UI
- **Docker containerization** for consistent deployment
- Secured via **Rack::Attack** for rate limiting
- **Cloudflare Turnstile** for bot protection
- **Redis caching** for optimal performance
- **Hotwire** for real-time updates without full page reloads

### Impact
- Built production-ready URL shortening service
- Comprehensive analytics providing valuable insights
- Secure and performant architecture handling high traffic
- Modern tech stack demonstrating full-stack Ruby on Rails expertise
